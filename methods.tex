
\section*{Methods and Files}


\subsection*{Seed Sequences}

FASTA file for the 210 seed protein sequences is at 
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/seed_sequences.faa}.
A manifest that lists the genome accession is at
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/seed_sequences.tsv}.

\subsubsection*{Protein sequences from NCBI genomes}

Genomic sequences and protein sequences (if available) from 35 coral genomes
and 10 symbiodinium genomes were downloaded from NCBI Genome database.
\textit{De novo} protein detection were also conducted on many of the genomes,
by searching 6-frame translations of the entire genome for hits against the
entire KEGG KO HMM database \cite{kofam}, using \texttt{hmmscan}
\cite{eddy2011hmmer}.

The source code for the \textit{de novo} searching program is available at
\texttt{https://github.com/benjiec/tangle-needle}. Proteins were assigned to KO
numbers using \texttt{https://github.com/benjiec/tangle-heap}.

\subsection*{Protein sequences from RNAseq data}

Table~\ref{tab:rnapapers} lists which transcriptomes and protein sequences were
generated by this paper. Docker environment and instructions for using Trinity
and TransDecoder \cite{trinity} are available at
\texttt{https://github.com/benjiec/tangle-pile}.


\subsection*{Removal of non-functional and/or partial protein sequences}

K04564 matching protein sequences were filtered to remove those that do not
contain both PF00081 and PF02777, and those that do not possess key residues
that form the metal binding pocket. A rule based filtering program was used.
The code for the program is available at
\texttt{https://github.com/benjiec/tangle-sieve}. The specific rule used for
each protein group is available at
\texttt{https://github.com/benjiec/tangle-coral/tree/main/coral/rules}.


\subsection*{Leader discovery}

Source code for leader discovery is available at
\texttt{https://github.com/benjiec/tangle-sieve}.  Start codons upstream and at
a specified distance from an anchor (e.g. where PF00081 aligns to a seed
protein sequence) are used as the start of a full length SOD2 sequence. If the
seed protein sequence comes from RNAseq data, start codon searching only occurs
in the TransDecoder generated protein sequence. If the seed protein sequence
comes from a NCBI protein file, with an associated genome GFF file, start codon
searching takes predicted exons from the GFF file into consideration. If the
seed protein sequence comes from de novo HMM search (see above), start codon
searching starts in frame with the anchor and looks upstream until hitting a
prior stop codon. Leader discovery in this last context is challenging and may
not find the correct start codon if the leader transcript was spliced together.

This paper choose to not use the patch to AUGUSTUS, available at
\texttt{http://smic.reefgenomics.org/download/}, because that patch assumes the
sequence motif frequency around each of the three DSS sites is independent of
the DSS sequence itself. Through inspection of likely DSS sites from several
symbiodinium genomes, that assumption does not appear to be valid.


\subsection*{Full length and mature SOD2 sequences}

147 full length sequences are available at
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/full_length.faa}.
The mature portions of the sequence, bounded by 3rd AA of PF00081 and 100th AA
of PF02777, inclusively, are available at
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/mature.faa}.
The reference mature sequences, included in the phylogenetic tree construction,
are available at
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/reference_mature.faa}.


\subsection*{Alignment and HMM profile construction}

Multi-sequence alignments of mature sequences were constructed using MUSCLE
\cite{muscle} after removing duplicate sequences. HMM profiles were constructed
using \texttt{hmmbuild} \cite{eddy2011hmmer} from the alignments.

The four HMM profiles are available at
\texttt{https://github.com/benjiec/paper-coral-sod2-hmm/blob/main/data/}.
